# 毕业论文下一阶段规划

更新日期：2026-09-08。

## 1. 当前严格基线

论文已经证明
\[
c_*:=\frac{9+\sqrt5+2\sqrt{35}}{18}
\leq \mathfrak c_3
\leq \frac{3+\sqrt5}{4}.
\]
下界由平衡 clique-\(C_5\) 六块构造给出；上界来自三维实最大绝对投影常数
\(\lambda_{\mathbb R}(3)=(1+\sqrt5)/2\)。此外，有限图极值比值的极限存在，
全局问题可等价写成三维各向同性矩问题，也可约化为至多 48 阶的
Stiefel--Perron 问题。

固定 clique-\(C_5\) 六块模板内部已经完成全局平衡化、唯一性和二次稳定性。
这不等于证明全体 graphon 都属于该模板。

## 2. 核心未决问题

目标猜想为
\[
\mathfrak c_3=c_*.
\]
其有限维形式是：对任意 \(Q\in\mathbb R^{N\times3}\)、
\(Q^{\mathsf T}Q=I_3\)，置 \(P=QQ^{\mathsf T}\)，证明
\[
\lambda_{\max}([P]_+)\leq c_*.
\]
取 \([P]_+\) 的非负单位 Perron 向量 \(s\)，等价地要控制耦合量
\[
s^{\mathsf T}[P]_+s
=\frac12\left(s^{\mathsf T}Ps+s^{\mathsf T}|P|_{\mathrm e}s\right).
\]

现有投影常数上界说明：任何违反候选上界的投影都必须满足
\[
\lambda_{\max}(|P|_{\mathrm e})
>2c_*-1
=\frac{\sqrt5+2\sqrt{35}}9
\approx1.5631363937.
\]
这一阈值距离投影常数极值 \((1+\sqrt5)/2\) 约为 \(0.0548975950\)。因此
后续无需在所有秩三投影上平均用力，只需研究该近极值窗口。进一步，若 \(s\) 是
\([P]_+\) 的单位 Perron 向量，则反例还必须满足
\[
  s^{\mathsf T}Ps>0.9576764280,
  \qquad
  \operatorname{dist}(s,\operatorname{Ran}P)<0.20573.
\]
这是耦合 Perron 方程与投影幂等性得到的严格必要条件，并非匹配上界本身。

## 3. 第一优先：投影常数亏损的耦合估计

### 3.1 目标

建立严格函数 \(\Phi\)，使
\[
s^{\mathsf T}Ps\leq
1-\Phi\!\left(\lambda_{\mathbb R}(3)
-s^{\mathsf T}|P|_{\mathrm e}s\right),
\]
并使右端与另一项相加后不超过 \(2c_*\)。关键不是再次分别估计两项，而是
利用它们来自同一个幂等投影以及同一个 Perron 向量。

### 3.2 可利用约束

1. \(P^2=P\)、\(P\succeq0\)、\(\operatorname{rank}P=3\)、
   \(\operatorname{Tr}P=3\)；
2. \(s\geq0\)、\(\|s\|_2=1\)，且 \([P]_+s=\rho([P]_+)s\)；
3. \(P_{ij}=q_i^{\mathsf T}q_j\)，其中 Parseval 标架满足
   \(\sum_iq_iq_i^{\mathsf T}=I_3\)；
4. 高能量各向同性分布的重心平方至少为 \(2c_*-\sqrt3\)；
5. 近投影常数等号情形应受三维极值标架的结构约束。

### 3.3 严格成果的分级

优先争取匹配上界；若暂时达不到，则依次接受以下可发表的中间结果：

1. 改进无条件常数 \(\mathfrak c_3\leq c_0<(3+\sqrt5)/4\)；
2. 证明进入近极值窗口的投影与某类三维极值标架接近；
3. 排除该极值标架邻域中对 \(\lambda_{\max}([P]_+)\) 的反例；
4. 给出带显式稳定余量的条件上界。

只有完整证明覆盖全部秩三投影后，才能把 \(\mathfrak c_3\leq c_*\) 写成定理。

## 4. 第二优先：极值 graphon 的六块结构约化

若直接耦合不等式过重，转向极值结构。现有极值分布同时满足各向同性矩条件、
符号必要条件、自支撑椭球、谱椭球等式、二阶必要条件以及正内积胞腔内的二次
重构。

下一步按以下顺序推进：

1. 分类二次固定点系统可能出现的正维退化分支；
2. 联立谱椭球和重心限制，排除与高能量相容的连续支撑；
3. 降低 48 原子上界，分析有限支撑点之间的正内积图；
4. 证明极值正内积图只能是一个核心点连接五边形；
5. 最后调用第六章已经完成的模板内平衡化。

这条路线首先追求“存在一个六块极值元”即可闭合数值上界；若要得到等号唯一性，
则必须对每一个全局极值元完成约化。

## 5. 第三优先：三阶外代数与严格计算

二特征值证明可用二维几何和二阶外代数闭合；三维中对应对象是三阶加法复合矩阵。
对结构筛选后剩下的有限模板，可尝试证明
\[
c_*I-B(d,A)^{[3]}\succeq0.
\]

纯解析消元过重时允许使用严格区间算术，但证明标准必须包括：

1. 有理或向外取整的区间端点；
2. 简单谱、重根和边界分支的完整覆盖；
3. 区间 Newton、Krawczyk 或半正定对偶证书的可独立验证输出；
4. 明确区分数值找候选与严格排除；
5. 固定随机种子、软件版本和证书哈希。

有限阶搜索只能帮助发现模板，不能代替全体 graphon 的结构约化。

## 6. 等号与稳定性

数值上界、等号分类和稳定性是三个不同层次：

1. 先证明 \(\mathfrak c_3\leq c_*\)；
2. 再证明达到 \(c_*\) 的各向同性分布模正交变换唯一；
3. 由 graphon 紧性推出定性 cut 稳定性；
4. 若进一步得到定量亏损，再研究
   \(\delta_\square(W,W_*)\leq C\sqrt{c_*-\sigma_3(W)}\) 一类速率。

在前两步未完成前，正文只能保留条件命题。
